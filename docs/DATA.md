# Data

No raw dataset is distributed in this repository.

The public release should document separately for every benchmark:

- official download URL and access terms;
- expected directory layout;
- the exact video/question subset used in the paper;
- a checksum for redistributable manifests only; and
- any preprocessing that changes timestamps or identifiers.

Small smoke-test fixtures may be added only when their redistribution rights
are explicit. Do not derive a fixture from a licensed benchmark merely because
it is small.
